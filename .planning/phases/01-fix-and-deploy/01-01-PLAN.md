**Step 4 — Rewrite `lib/og-utils.ts`:**

Replace the entire font loading section. Changes:
1. Import `readFile` from `node:fs/promises` instead of `readFileSync` from `fs`
2. Import `join` from `node:path` instead of `path`
3. Make `getOgFonts()` async — returns `Promise<OgFont[]>`
4. Remove the `fontsCache` module-level variable (no benefit on serverless)
5. Change font file extensions from `.woff2` to `.ttf`
6. Pass Buffer directly with `as unknown as ArrayBuffer` cast (no `.buffer` accessor)
7. Also make `staticOgFallback()` async using `readFile` for consistency

The updated `getOgFonts` function:
```typescript
import { readFile } from 'node:fs/promises'
import { join } from 'node:path'

export async function getOgFonts(): Promise<OgFont[]> {
  const fontsDir = join(process.cwd(), 'public', 'fonts')
  const [dmSerif, geist] = await Promise.all([
    readFile(join(fontsDir, 'DMSerifDisplay-Regular.ttf')),
    readFile(join(fontsDir, 'Geist-Regular.ttf')),
  ])

  return [
    { name: 'DM Serif Display', data: dmSerif as unknown as ArrayBuffer, weight: 400, style: 'normal' as const },
    { name: 'Geist', data: geist as unknown as ArrayBuffer, weight: 400, style: 'normal' as const },
  ]
}
```

Also update `staticOgFallback` to async:
```typescript
export async function staticOgFallback(): Promise<Response> {
  const imageBuffer = await readFile(join(process.cwd(), 'public', 'og-image.png'))
  return new Response(imageBuffer, {
    headers: { 'Content-Type': 'image/png' },
  })
}
```

Keep `OG_SIZE`, `OG_COLORS`, `fetchAvatarAsDataUri`, and `truncate` unchanged.
